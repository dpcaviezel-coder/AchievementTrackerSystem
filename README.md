AchievementTrackerSystem
This project was created to strengthen my understanding of object-oriented programming in C#. The application tracks player achievements and allows achievements to be unlocked, displayed, and managed through a centralized achievement tracker.

Concepts Practiced
Classes and Objects
Constructors
Properties
Methods
Encapsulation
List Collections
Object State Management
Collection Filtering
Console Applications
System Design
Gamer ↓ AchievementTracker ↓ Achievements

The AchievementTracker class manages a collection of Achievement objects for a specific gamer. Achievements can be unlocked and tracked throughout the application.

Features
Create Gamers
Create Achievements
Unlock Achievements
Display All Achievements
Display Unlocked Achievements
Display Locked Achievements
Calculate Total Achievement Points
